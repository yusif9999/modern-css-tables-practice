# Tech Summit Landing Page

A modern, well-structured landing page for a fictional technology conference. This project was built to practice and demonstrate foundational CSS styling techniques, specifically focusing on advanced typography and list formatting.

## 🎯 Project Focus & Learnings

This repository showcases the implementation of the following HTML/CSS concepts:

*   **Advanced Typography:** Using the `::first-letter` pseudo-element to create a magazine-style drop cap effect, along with `text-shadow` and `font-variant`.
*   **Custom List Styling:** Overriding default unordered list (`<ul>`) behaviors using `list-style-type` and `list-style-position`, and integrating FontAwesome icons for a customized look.
*   **CSS Combinators & Pseudo-classes:** Utilizing adjacent sibling selectors (e.g., `p+div`) and the `:last-child` pseudo-class to style elements efficiently without bloating the HTML with extra classes.
*   **Table Formatting:** Designing clean HTML tables using `border-collapse`, custom headers (`thead`), and refined padding/border properties.
*   **Global CSS Reset:** Applying a universal reset (`* { box-sizing: border-box; margin: 0; padding: 0; }`) to ensure consistent rendering.

## 🚀 Technologies Used

*   **HTML5** - Semantic markup
*   **CSS3** - Styling, layout, and visual effects
*   **Google Fonts** - Typography (Roboto Mono, Montserrat, Open Sans)
*   **FontAwesome** - Iconography

## 📂 How to Run

1. Clone this repository to your local machine.
2. Open the `index.html` file in any modern web browser.
3. No external server or build tools are required.
